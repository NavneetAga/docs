---
title: Check Membership Credentials
description: Validate a member's password for authentication.
---

## Endpoint

```
POST https://{domain}/lbms-ingress/member/api/Member/CheckMembershipCredentialsByRelationReference
```

## When to Use

Use this for password-based member login. The API checks the supplied password against the stored hashed password for the given `RelationReference` and returns the full member profile on success.

For OTP-based login, use [Generate OTP by Relation Reference](/api-reference/otp/generate-otp-by-relation) followed by [Verify OTP by Relation Reference](/api-reference/otp/verify-otp-by-relation).

## Request

### Headers

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

### Body

<ParamField body="UniquerefID" type="string" required>
  The member's `RelationReference`.
</ParamField>

<ParamField body="ProgramId" type="integer" required>
  Your loyalty program ID.
</ParamField>

<ParamField body="RelationType" type="integer" required>
  Relation type. Use `4` for customers.
</ParamField>

<ParamField body="Password" type="string" required>
  The member's password, hashed using **bcrypt** or **MD5** as configured for your program.
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request POST \
  --url 'https://{domain}/lbms-ingress/member/api/Member/CheckMembershipCredentialsByRelationReference' \
  --header 'Authorization: bearer {token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "UniquerefID": "jane.doe@example.com",
    "ProgramId": 19,
    "RelationType": 4,
    "Password": "{hashed_password}"
  }'
```

</CodeGroup>

## Response

### 200 — Success

```json
{
  "results": {
    "IsSucessful": true,
    "ErrorCode": "000",
    "ExceptionMessage": "Success",
    "ReturnObject": {
      "Id": 12345,
      "FullName": "Jane Doe",
      "Email": "jane.doe@example.com"
    }
  }
}
```

The `ReturnObject` contains the full member profile on successful authentication.

### Error (wrong password)

```json
{
  "results": {
    "IsSucessful": false,
    "ErrorCode": "E401",
    "ExceptionMessage": "Invalid credentials"
  }
}
```
