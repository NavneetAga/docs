---
title: Check Membership Credentials
description: Validate a member's password for authentication.
openapi: "POST /lbms-ingress/member/api/Member/CheckMembershipCredentialsByRelationReference"
---

## When to Use

Use this for password-based member login. For OTP-based login, use [Generate OTP by Relation Reference](/api-reference/otp/generate-otp-by-relation) → [Verify OTP by Relation Reference](/api-reference/otp/verify-otp-by-relation).

## Authorization

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

## Body Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `UniquerefID` | string | Yes | The member's `RelationReference` |
| `ProgramId` | integer | Yes | Your loyalty program ID |
| `RelationType` | integer | Yes | Use `4` for customers |
| `Password` | string | Yes | Member's password hashed using bcrypt or MD5 as configured for your program |

## Responses

### 200 — Success

| Path | Type | Description |
|---|---|---|
| `results.IsSucessful` | boolean | `true` |
| `results.ErrorCode` | string | `000` |
| `results.ReturnObject.Id` | integer | Internal member ID |
| `results.ReturnObject.FullName` | string | Member's full name |
| `results.ReturnObject.Email` | string | Member's email |

### 401 — Invalid Credentials

| Path | Type | Description |
|---|---|---|
| `results.IsSucessful` | boolean | `false` |
| `results.ErrorCode` | string | `E401` |
| `results.ExceptionMessage` | string | `Invalid credentials` |
