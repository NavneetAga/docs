---

## When to Use

Use this for password-based member login. The API checks the supplied password against the stored hashed credential for the given `RelationReference` and returns the full member profile on success.

For OTP-based login, use [Generate OTP by Relation Reference](/api-reference/otp/generate-otp-by-relation) followed by [Verify OTP by Relation Reference](/api-reference/otp/verify-otp-by-relation).
