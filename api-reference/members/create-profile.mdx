---
title: Create Profile
description: Enroll a new member in your loyalty program.
---

## Endpoint

```
POST https://{domain}/lbms-ingress/member/api/Member/CreateProfileWithAttributes?pintProgramId={ProgramId}
```

## Request

### Headers

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

### Query Parameters

<ParamField query="pintProgramId" type="integer" required>
  Your loyalty program ID.
</ParamField>

### Body

<ParamField body="relation_reference" type="string" required>
  Unique member identifier — typically an email-based reference (e.g. `jane.doe@example.com`). This is the primary key used to identify the member across all APIs.
</ParamField>

<ParamField body="full_name" type="string" required>
  Member's full name.
</ParamField>

<ParamField body="email_id" type="string" required>
  Member's email address.
</ParamField>

<ParamField body="mobile_number" type="string" required>
  Member's mobile number.
</ParamField>

<ParamField body="status" type="string" required>
  Member status code. Use `"5"` for Inactive (the standard initial state for new enrollments).
</ParamField>

<ParamField body="address" type="string">
  Member's address.
</ParamField>

<ParamField body="gender" type="string">
  Member's gender. Allowed values: `M`, `F`, `O`.
</ParamField>

<ParamField body="dob" type="string">
  Date of birth in `YYYY-MM-DD` format.
</ParamField>

<Note>
  Any mandatory custom attributes defined in your CPD schema must also be included. Optional custom attributes defined in your schema can also be passed.
</Note>
