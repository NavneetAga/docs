---
title: Get Member Profile
description: Retrieve complete profile details for a member by their RelationReference.
---

## Endpoint

```
GET https://{domain}/lbms-ingress/member/api/Member/GetMemberProfile
```

## Request

### Headers

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

### Query Parameters

<ParamField query="pintProgramId" type="integer" required>
  Your loyalty program ID.
</ParamField>

<ParamField query="pintRelationType" type="integer" required>
  Relation type. Use `4` for customers.
</ParamField>

<ParamField query="pstrRelationReference" type="string" required>
  The member's unique reference identifier. **URL-encode this value before passing.**
</ParamField>

<Warning>
  Query parameters must be URL-encoded before sending. For example, `jane.doe@example.com` becomes `jane.doe%40example.com`.
</Warning>

### Example Request

<CodeGroup>

```bash cURL
curl --request GET \
  --url 'https://{domain}/lbms-ingress/member/api/Member/GetMemberProfile?pintProgramId=19&pintRelationType=4&pstrRelationReference=jane.doe%40example.com' \
  --header 'Authorization: bearer {token}' \
  --header 'Content-Type: application/json'
```

```python Python
import requests
from urllib.parse import quote

relation_reference = "jane.doe@example.com"

res = requests.get(
    "https://{domain}/lbms-ingress/member/api/Member/GetMemberProfile",
    params={
        "pintProgramId": 19,
        "pintRelationType": 4,
        "pstrRelationReference": relation_reference
    },
    headers={"Authorization": "bearer {token}", "Content-Type": "application/json"}
)
member = res.json()["results"]["ReturnObject"]
```

</CodeGroup>

## Response

### 200 — Success

```json
{
  "results": {
    "IsSucessful": true,
    "ErrorCode": "000",
    "ExceptionMessage": "Success",
    "ReturnObject": {
      "Id": 12345,
      "FullName": "Jane Doe",
      "Email": "jane.doe@example.com",
      "MobileNumber": "+919876543210",
      "Status": "Active",
      "TierName": "Silver",
      "TotalPoints": 1500
    }
  }
}
```

<ResponseField name="results.ReturnObject.Id" type="integer">
  Internal member ID — required for `UpdateProfileWithAttributes`.
</ResponseField>

<ResponseField name="results.ReturnObject.FullName" type="string">
  Member's full name.
</ResponseField>

<ResponseField name="results.ReturnObject.TierName" type="string">
  Current loyalty tier (e.g. Silver, Gold, Platinum).
</ResponseField>

<ResponseField name="results.ReturnObject.TotalPoints" type="integer">
  Total points in the member's account.
</ResponseField>
