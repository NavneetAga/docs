---
title: Get Member by Attribute
description: Look up a member using a unique attribute such as email when RelationReference is unknown.
openapi: "GET /lbms-ingress/member/api/Member/GetMemberDetailsByUniqueAttribute"
---

Looks up a member using any unique profile attribute — such as `email_id` or `mobile_number` — when their `RelationReference` is not available. This is useful during customer support workflows or third-party integrations where only a known identifier like email is on hand. The attribute you search by must be defined in your Loyalife User schema and marked as unique; searching by non-unique fields is not supported.

## Authorization

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |

## Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `pintProgramId` | integer | Yes | Your loyalty program ID |
| `pstrUniqueAttributeKey` | string | Yes | Attribute name to search by (e.g. `email_id`, `mobile_number`). URL-encode before passing. |
| `pstrUniqueAttributeValue` | string | Yes | Value to search for. URL-encode before passing. |
