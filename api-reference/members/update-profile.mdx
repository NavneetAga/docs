---
title: Update Profile
description: Update an existing member's profile attributes.
openapi: "POST /lbms-ingress/member/api/Member/UpdateProfileWithAttributes"
---

Updates one or more profile fields for an existing member. Only the fields you include in the `data` object are changed — omitted fields are left unchanged. The internal `id` (not `RelationReference`) is required as the update key; obtain it from [Get Member Profile](/api-reference/members/get-member-profile) first. Custom attributes defined in your CPD schema can be updated the same way as standard fields.

## Authorization

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

## Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `pintProgramId` | integer | Yes | Your loyalty program ID |

## Body Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | integer | Yes | Internal member ID from Get Member Profile response |
| `data.email_id` | string | No | Updated email address |
| `data.full_name` | string | No | Updated full name |
| `data.gender` | string | No | `M`, `F`, or `O` |
| `data.dob` | string | No | Updated date of birth in `YYYY-MM-DD` |
| `data.mobile_number` | string | No | Updated mobile number |
| `data.address` | string | No | Updated address |

<Note>
  At least one `data.*` field must be present. Custom attributes from your CPD schema can also be included under `data`.
</Note>

## Responses

<AccordionGroup>
  <Accordion title="200 — Success">
    | Path | Type | Description |
    |---|---|---|
    | `results.IsSucessful` | boolean | `true` |
    | `results.ErrorCode` | string | `000` |
    | `results.ExceptionMessage` | string | `Success` |
    | `results.ReturnObject` | boolean | `true` on successful update |
  </Accordion>
</AccordionGroup>
