## When to Use

After submitting a batch with [Insert Transaction V2](/api-reference/transactions/insert-transaction-v2), poll this endpoint to retrieve the aggregate summary and per-transaction outcomes.

**Poll until `summary.pending === 0`** (or your SLA timeout is reached), using exponential backoff between polls.

## Per-Item Status Values

| Status | Meaning |
|---|---|
| `SUCCESS` | Processed successfully. `points` shows awarded points. |
| `FAILED` | Processing failed. `error` contains the reason. Contact support with `request_id`. |
| `ON HOLD` | Transaction held — Points Hold is enabled or Anomaly Detection triggered. No points until reviewed. |
| `PARTIAL HOLD` | Some rewards awarded; remaining held for review. |
| `PENDING` | Still processing. Continue polling with backoff. |

<Warning>
  Keep polling until `summary.pending === 0`. Items in `PENDING` state are not yet finalized — their outcome may change.
</Warning>
