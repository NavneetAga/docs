---
title: Get Expiry Schedule
description: Retrieve the periodic points expiry schedule for a member.
---

## Endpoint

```
POST https://{domain}/lbms-ingress/transaction-lm/API/Transaction/GetExpirySchedule
```

## When to Use

Use this to display upcoming points expiry information to a member — for example, showing how many points expire each quarter. Useful for driving engagement and pre-expiry redemption.

## Request

### Headers

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

### Body

<ParamField body="RelationReference" type="string" required>
  The member's unique reference.
</ParamField>

<ParamField body="RelationType" type="integer" required>
  Use `4` for customers.
</ParamField>

<ParamField body="ProgramId" type="integer" required>
  Your loyalty program ID.
</ParamField>

<ParamField body="TransactionCurrency" type="string" required>
  Use `"DEFAULT"`.
</ParamField>

<ParamField body="Year" type="integer" required>
  The year for which to retrieve the expiry schedule (e.g. `2026`).
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request POST \
  --url 'https://{domain}/lbms-ingress/transaction-lm/API/Transaction/GetExpirySchedule' \
  --header 'Authorization: bearer {token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "RelationReference": "jane.doe@example.com",
    "RelationType": 4,
    "ProgramId": 19,
    "TransactionCurrency": "DEFAULT",
    "Year": 2026
  }'
```

</CodeGroup>

## Response

### 200 — Success

```json
{
  "results": {
    "IsSucessful": true,
    "ErrorCode": "000",
    "ExceptionMessage": "Success",
    "ReturnObject": {
      "Period": "Quarterly",
      "ExpiryPeriod": [
        {
          "ScheduleDate": "2026-03-31T00:00:00",
          "AccrualPoints": 500,
          "RedeemPoints": 100,
          "BlockedPoints": 0,
          "TotalAvailablePoints": 400
        },
        {
          "ScheduleDate": "2026-06-30T00:00:00",
          "AccrualPoints": 300,
          "RedeemPoints": 50,
          "BlockedPoints": 0,
          "TotalAvailablePoints": 250
        }
      ]
    }
  }
}
```

<ResponseField name="results.ReturnObject.Period" type="string">
  The expiry period type — typically `"Quarterly"`.
</ResponseField>

<ResponseField name="results.ReturnObject.ExpiryPeriod[].ScheduleDate" type="string">
  Date when this batch of points expires.
</ResponseField>

<ResponseField name="results.ReturnObject.ExpiryPeriod[].AccrualPoints" type="integer">
  Points accrued in this period.
</ResponseField>

<ResponseField name="results.ReturnObject.ExpiryPeriod[].TotalAvailablePoints" type="integer">
  Points still available (accrual minus redeemed and blocked).
</ResponseField>
