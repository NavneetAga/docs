## When to Use

Use this for **synchronous** single-transaction submission. The transaction is immediately processed by the Rule Engine to compute and award loyalty points.

For high-volume or batch submissions, use [Insert Transaction V2](/api-reference/transactions/insert-transaction-v2) which processes asynchronously and returns a `batch_id` for polling.

## Notes

- Field names and validation rules are enforced per your program's event template — align `product_code`, `transaction_type`, and mandatory columns with your onboarding pack.
- Custom attributes (e.g. store, quantity, category) must be created in Loyalife Admin before including them in the payload.
