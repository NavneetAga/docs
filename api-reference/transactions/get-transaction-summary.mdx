---
title: Get Transaction Summary by Date
description: Retrieve a paginated list of a member's loyalty transactions within a date range.
---

## Endpoint

```
POST https://{domain}/lbms-ingress/transaction-lm/API/Transaction/GetMemberTransactionSummaryByDate
```

## Request

### Headers

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

### Body

<ParamField body="DateFrom" type="string" required>
  Start date in ISO 8601 format (e.g. `2026-01-01T00:00:00`).
</ParamField>

<ParamField body="DateTo" type="string" required>
  End date in ISO 8601 format (e.g. `2026-05-11T23:59:59`).
</ParamField>

<ParamField body="MinimumRange" type="integer" required>
  Pagination start index (0-based). Use `0` for the first page.
</ParamField>

<ParamField body="MaximumRange" type="integer" required>
  Number of records to return per page (e.g. `10`, `25`, `100`).
</ParamField>

<ParamField body="RelationReference" type="string" required>
  The member's unique reference.
</ParamField>

<ParamField body="TransactionCurrency" type="string" required>
  Use `"DEFAULT"` or a specific currency code configured for your program.
</ParamField>

<ParamField body="RelationType" type="integer" required>
  Use `4` for customers.
</ParamField>

<ParamField body="ProgramId" type="integer" required>
  Your loyalty program ID.
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request POST \
  --url 'https://{domain}/lbms-ingress/transaction-lm/API/Transaction/GetMemberTransactionSummaryByDate' \
  --header 'Authorization: bearer {token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "DateFrom": "2026-01-01T00:00:00",
    "DateTo": "2026-05-11T23:59:59",
    "MinimumRange": 0,
    "MaximumRange": 10,
    "RelationReference": "jane.doe@example.com",
    "TransactionCurrency": "DEFAULT",
    "RelationType": 4,
    "ProgramId": 19
  }'
```

```python Python
import requests

res = requests.post(
    "https://{domain}/lbms-ingress/transaction-lm/API/Transaction/GetMemberTransactionSummaryByDate",
    headers={"Authorization": "bearer {token}", "Content-Type": "application/json"},
    json={
        "DateFrom": "2026-01-01T00:00:00",
        "DateTo": "2026-05-11T23:59:59",
        "MinimumRange": 0,
        "MaximumRange": 10,
        "RelationReference": "jane.doe@example.com",
        "TransactionCurrency": "DEFAULT",
        "RelationType": 4,
        "ProgramId": 19
    }
)
transactions = res.json()["results"]["ReturnObject"]
```

</CodeGroup>

<ResponseField name="results.ReturnObject[].Id" type="integer">
  Internal transaction ID.
</ResponseField>

<ResponseField name="results.ReturnObject[].Points" type="integer">
  Points earned or redeemed in this transaction.
</ResponseField>

<ResponseField name="results.ReturnObject[].Narration" type="string">
  Human-readable description (e.g. `"Referral Bonus"`, `"Spend Points"`).
</ResponseField>

<ResponseField name="results.ReturnObject[].ExpiryDate" type="string">
  When the awarded points expire.
</ResponseField>

<ResponseField name="results.ReturnObject[].LoyaltyTxnType" type="integer">
  Transaction type code: `1` = Spend, `2` = Earn/Bonus.
</ResponseField>

<ResponseField name="results.Count" type="integer">
  Total number of matching records (used for pagination).
</ResponseField>

## Pagination

To retrieve the next page, increment `MinimumRange` by your page size:

```json
{ "MinimumRange": 10, "MaximumRange": 10 }  // page 2
{ "MinimumRange": 20, "MaximumRange": 10 }  // page 3
```
