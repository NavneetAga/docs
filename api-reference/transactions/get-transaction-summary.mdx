---
title: Get Transaction Summary by Date
description: Retrieve a paginated list of a member's loyalty transactions within a date range.
openapi: "POST /lbms-ingress/transaction-lm/API/Transaction/GetMemberTransactionSummaryByDate"
---

## Pagination

Use `MinimumRange` and `MaximumRange` to page through results. `Count` in the response is the total number of matching records.

```
Page 1: MinimumRange=0,  MaximumRange=10
Page 2: MinimumRange=10, MaximumRange=10
Page 3: MinimumRange=20, MaximumRange=10
```
