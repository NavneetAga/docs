## When to Use

Always call this **before** [Redeem Points](/api-reference/payment-gateway/redeem-points) to confirm the member has enough points. `ReturnObject` is the integer balance.

## Typical Flow

```
CheckAvailability → (confirm balance ≥ required points) → RedeemPoints → (on failure/cancel) → ReversalPoints
```
