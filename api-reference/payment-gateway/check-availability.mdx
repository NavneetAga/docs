---
title: Check Availability
description: Verify a member's redeemable points balance before initiating a redemption.
openapi: "POST /lbms-ingress/pg-lm/API/PG/CheckAvailability"
---

Always call this **before** [Redeem Points](/api-reference/payment-gateway/redeem-points) to confirm the member has enough points.

## Body Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `RelationReference` | string | Yes | The member's unique reference |
| `TransactionCurrency` | string | Yes | Use `DEFAULT` |
| `RelationType` | integer | Yes | Use `4` for customers |
| `ProgramId` | integer | Yes | Your loyalty program ID |

## Response Schema

| Path | Type | Description |
|---|---|---|
| `results.IsSucessful` | boolean | `true` on success |
| `results.ErrorCode` | string | `000` on success |
| `results.ExceptionMessage` | string | `Success` or error description |
| `results.ReturnObject` | integer | **The member's current redeemable points balance** |

## Typical Flow

```
CheckAvailability → (confirm balance ≥ required points) → RedeemPoints → (on failure/cancel) → ReversalPoints
```
