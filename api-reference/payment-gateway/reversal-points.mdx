## When to Use

Use this when a redemption needs to be cancelled — for example, if the downstream fulfillment failed (booking error, gift card not issued, etc.). The deducted points are restored to the member's balance.

You must have the `ExternalReference` UUID returned by [Redeem Points](/api-reference/payment-gateway/redeem-points).

## Redemption Flow

```
CheckAvailability
    ↓ (balance confirmed)
RedeemPoints → save ExternalReference
    ↓ (fulfillment succeeds)
  Done
    ↓ (fulfillment fails / cancel)
ReversalPoints (using ExternalReference)
```
