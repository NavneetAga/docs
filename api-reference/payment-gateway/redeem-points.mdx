---
title: Redeem Points
description: Deduct points from a member's balance to complete a redemption transaction.
---

## Endpoint

```
POST https://{domain}/lbms-ingress/pg-lm/API/PG/RedeemPoints
```

## When to Use

Call this after [Check Availability](/api-reference/payment-gateway/check-availability) confirms the member has sufficient points. On success, the points are deducted and an `ExternalReference` (UUID) is returned — save this for potential [reversals](/api-reference/payment-gateway/reversal-points).

## Request

### Headers

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

### Body

<ParamField body="RelationReference" type="string" required>
  The member's unique reference.
</ParamField>

<ParamField body="Amount" type="number" required>
  Monetary value equivalent of the redemption.
</ParamField>

<ParamField body="Points" type="integer" required>
  Number of points to deduct from the member's balance.
</ParamField>

<ParamField body="MerchantName" type="string" required>
  The merchant or redemption channel name (e.g. `"Amazon"`, `"Flight Booking"`).
</ParamField>

<ParamField body="LoyaltyTxnType" type="integer" required>
  Redemption category code:

  | Value | Category |
  |---|---|
  | `5` | Hotel |
  | `6` | Air / Flight |
  | `19` | Charity |
  | `30` | Gift Card |

  Contact your Xoxoday onboarding contact for the full list applicable to your program.
</ParamField>

<ParamField body="TransactionCurrency" type="string" required>
  Use `"DEFAULT"`.
</ParamField>

<ParamField body="RelationType" type="integer" required>
  Use `4` for customers.
</ParamField>

<ParamField body="ProgramId" type="integer" required>
  Your loyalty program ID.
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request POST \
  --url 'https://{domain}/lbms-ingress/pg-lm/API/PG/RedeemPoints' \
  --header 'Authorization: bearer {token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "RelationReference": "jane.doe@example.com",
    "Amount": 500,
    "Points": 500,
    "MerchantName": "Amazon",
    "LoyaltyTxnType": 30,
    "TransactionCurrency": "DEFAULT",
    "RelationType": 4,
    "ProgramId": 19
  }'
```

```python Python
import requests

res = requests.post(
    "https://{domain}/lbms-ingress/pg-lm/API/PG/RedeemPoints",
    headers={"Authorization": "bearer {token}", "Content-Type": "application/json"},
    json={
        "RelationReference": "jane.doe@example.com",
        "Amount": 500,
        "Points": 500,
        "MerchantName": "Amazon",
        "LoyaltyTxnType": 30,
        "TransactionCurrency": "DEFAULT",
        "RelationType": 4,
        "ProgramId": 19
    }
)
external_ref = res.json()["results"]["ReturnObject"]
# Save external_ref — needed for ReversalPoints
```

</CodeGroup>

## Response

### 200 — Success

```json
{
  "results": {
    "IsSucessful": true,
    "ErrorCode": "000",
    "ExceptionMessage": "Success",
    "ReturnObject": "3FA85F64-5717-4562-B3FC-2C963F66AFA6"
  }
}
```

<ResponseField name="results.ReturnObject" type="string">
  A UUID (`ExternalReference`) for this redemption transaction. **Store this — it is required to reverse the transaction.**
</ResponseField>

<Warning>
  Save the `ExternalReference` UUID immediately. If the downstream fulfillment fails, you'll need it to call [Reversal Points](/api-reference/payment-gateway/reversal-points) and restore the member's balance.
</Warning>
