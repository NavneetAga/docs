---
title: Redeem Points
description: Deduct points from a member's balance to complete a redemption transaction.
openapi: "POST /lbms-ingress/pg-lm/API/PG/RedeemPoints"
---

## When to Use

Call this after [Check Availability](/api-reference/payment-gateway/check-availability) confirms the member has sufficient points. On success, the points are deducted and an `ExternalReference` UUID is returned.

<Warning>
  Save the `ExternalReference` UUID immediately. If the downstream fulfillment fails, you'll need it to call [Reversal Points](/api-reference/payment-gateway/reversal-points) and restore the member's balance.
</Warning>
