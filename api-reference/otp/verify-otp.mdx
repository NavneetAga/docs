---
title: Verify OTP
description: Validate an OTP sent via Generate OTP (email-based).
openapi: "POST /lbms-ingress/member/api/Member/VerifyOTP"
---

## When to Use

Step 2 of the OTP flow started by [Generate OTP](/api-reference/otp/generate-otp). For flows started via [Generate OTP by Relation Reference](/api-reference/otp/generate-otp-by-relation), use [Verify OTP by Relation Reference](/api-reference/otp/verify-otp-by-relation).

## Authorization

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

## Body Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `UniquerefID` | string | Yes | The member's email address |
| `OTP` | integer | Yes | The OTP entered by the member |
| `DestinationAddress` | string | Yes | IP address of the client device |
| `Destination` | string | Yes | `Web` or `Mobile` |
| `OtpType` | string | Yes | Must match the `OtpType` used in `GenerateOTP` |
| `ProgramId` | integer | Yes | Your loyalty program ID |
| `RelationType` | integer | Yes | Use `4` for customers |

## Responses

### 200 — Success

| Path | Type | Description |
|---|---|---|
| `results.IsSucessful` | boolean | `true` |
| `results.ErrorCode` | string | `000` |
| `results.ExceptionMessage` | string | `Success` |
| `results.ReturnObject` | boolean | `true` on successful verification |

### 400 — Invalid OTP

| Path | Type | Description |
|---|---|---|
| `results.IsSucessful` | boolean | `false` |
| `results.ErrorCode` | string | `E400` |
| `results.ExceptionMessage` | string | `Invalid or expired OTP` |
