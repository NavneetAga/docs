---
title: Verify OTP
description: Validate an OTP sent via Generate OTP (email-based).
---

## Endpoint

```
POST https://{domain}/lbms-ingress/member/api/Member/VerifyOTP
```

## When to Use

This is step 2 of the OTP flow initiated by [Generate OTP](/api-reference/otp/generate-otp). Use it when `UniquerefID` is the member's **email address**.

For flows initiated by [Generate OTP by Relation Reference](/api-reference/otp/generate-otp-by-relation), use [Verify OTP by Relation Reference](/api-reference/otp/verify-otp-by-relation).

## Request

### Headers

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

### Body

<ParamField body="UniquerefID" type="string" required>
  The member's email address.
</ParamField>

<ParamField body="OTP" type="integer" required>
  The OTP entered by the member.
</ParamField>

<ParamField body="DestinationAddress" type="string" required>
  IP address of the client device.
</ParamField>

<ParamField body="Destination" type="string" required>
  Channel from which the OTP is being verified. Use `Web` or `Mobile`.
</ParamField>

<ParamField body="OtpType" type="string" required>
  Must match the `OtpType` used in `GenerateOTP` (e.g. `FORGOTPWD`, `LOGIN`).
</ParamField>

<ParamField body="ProgramId" type="integer" required>
  Your loyalty program ID.
</ParamField>

<ParamField body="RelationType" type="integer" required>
  Use `4` for customers.
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request POST \
  --url 'https://{domain}/lbms-ingress/member/api/Member/VerifyOTP' \
  --header 'Authorization: bearer {token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "UniquerefID": "jane.doe@example.com",
    "OTP": 123456,
    "DestinationAddress": "192.168.1.1",
    "Destination": "Web",
    "OtpType": "FORGOTPWD",
    "ProgramId": 19,
    "RelationType": 4
  }'
```

</CodeGroup>

## Response

### 200 — Success

```json
{
  "results": {
    "IsSucessful": true,
    "ErrorCode": "000",
    "ExceptionMessage": "Success",
    "ReturnObject": true
  }
}
```

### Error (invalid OTP)

```json
{
  "results": {
    "IsSucessful": false,
    "ErrorCode": "E400",
    "ExceptionMessage": "Invalid or expired OTP"
  }
}
```
