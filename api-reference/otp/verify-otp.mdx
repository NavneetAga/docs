## When to Use

This is step 2 of the OTP flow initiated by [Generate OTP](/api-reference/otp/generate-otp). Use it when `UniquerefID` is the member's **email address**.

For flows initiated by [Generate OTP by Relation Reference](/api-reference/otp/generate-otp-by-relation), use [Verify OTP by Relation Reference](/api-reference/otp/verify-otp-by-relation).

The `OtpType` must match the value used in `GenerateOTP`.
