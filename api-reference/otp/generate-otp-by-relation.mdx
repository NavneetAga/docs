---
title: Generate OTP by Relation Reference
description: Send an OTP to a member using their RelationReference (CID).
---

## Endpoint

```
POST https://{domain}/lbms-ingress/member/api/Member/GenerateOTPByRelationReference
```

## When to Use

Use this when the member's **RelationReference (CID)** is known. This is the preferred flow for OTP-based login when the member identifier is already available in your system.

If you only know the member's email, use [Generate OTP](/api-reference/otp/generate-otp) instead.

## Request

### Headers

| Header | Value | Required |
|---|---|---|
| `Authorization` | `bearer {token}` | Yes |
| `Content-Type` | `application/json` | Yes |

### Body

<ParamField body="UniquerefID" type="string" required>
  The member's `RelationReference` (CID).
</ParamField>

<ParamField body="SourceCode" type="integer" required>
  Origin of the request: `1` = Web, `2` = Mobile, `3` = Email, `4` = Service.
</ParamField>

<ParamField body="SourceAddress" type="string" required>
  IP address of the requesting system.
</ParamField>

<ParamField body="OtpType" type="string" required>
  Purpose of the OTP. Common values: `LOGIN`, `FORGOTPWD`, `ACTIVATION`, `TwoFA`. See [Generate OTP](/api-reference/otp/generate-otp) for the full list.
</ParamField>

<ParamField body="ProgramId" type="integer" required>
  Your loyalty program ID.
</ParamField>

<ParamField body="RelationType" type="integer" required>
  Use `4` for customers.
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request POST \
  --url 'https://{domain}/lbms-ingress/member/api/Member/GenerateOTPByRelationReference' \
  --header 'Authorization: bearer {token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "UniquerefID": "jane.doe@example.com",
    "SourceCode": 1,
    "SourceAddress": "192.168.1.1",
    "OtpType": "LOGIN",
    "ProgramId": 19,
    "RelationType": 4
  }'
```

</CodeGroup>

## Response

### 200 — Success

```json
{
  "results": {
    "IsSucessful": true,
    "ErrorCode": "000",
    "ExceptionMessage": "Success",
    "ReturnObject": true,
    "Count": 0
  }
}
```

Verify the OTP using [Verify OTP by Relation Reference](/api-reference/otp/verify-otp-by-relation).
